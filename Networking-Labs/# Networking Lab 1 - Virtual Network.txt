## Key Concepts Learned

### Virtual Network (VNet)
An isolated network in Azure.

### Subnet
A logical division within a VNet.

### Network Security Group (NSG)
A virtual firewall that controls traffic.

## NSG Rules

Created custom inbound rules:

- Allow HTTP (Port 80)
- Allow HTTPS (Port 443)

Learned that NSGs evaluate rules by priority and stop at the first matching rule.

## Custom NSG Rules

Created two inbound security rules:

| Rule | Port | Priority |
|------|------|----------|
| Allow-HTTP | 80 | 100 |
| Allow-HTTPS | 443 | 110 |

Observed Azure default rules:

| Rule | Priority |
|------|----------|
| AllowVnetInBound | 65000 |
| AllowAzureLoadBalancerInBound | 65001 |
| DenyAllInbound | 65500 |

### Key Learning

Network Security Groups process rules from the lowest priority number to the highest. The first matching rule is applied.
